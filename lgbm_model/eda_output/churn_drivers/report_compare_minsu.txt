1) 임계값별 핵심 비교

1. 임계값 (Threshold) : 모델이 예측한 이탈확률이 이 값 이상이면 이탈로, 미만이면 잔존으로 분류하는 기준값
기본 (thr=0.500)
TPR 0.794 → 실제 이탈 고객의 79%를 잡음(이탈 포착력 높음).
예측 이탈률 43.05%, 실제보다 +17.8%p 많음 → 과대추정.
장점: 이탈을 놓치지 않음(리스크 최소화).
단점: 정상 고객을 이탈로 잘못 분류하는 비율 높음 → 마케팅 비용 낭비.
2. ACC (Accuracy) : 전체 예측 중 정답 비율. 하지만 데이터 불균형(이탈 vs 비이탈 비율)이 있으면 한쪽에 치우쳐도 높게 나올 수 있음
Accuracy 최대 (thr=0.705) → 이탈률 추정 추천
ACC 0.792 → 전체 정확도 최고.
예측 이탈률 23.40%, 실제 25.25%와 편차 -1.86%p → 실제와 가장 근접.
장점: "전체 고객 중 몇 %가 이탈할까?"라는 비율 예측에 최적.
단점: TPR 0.553 → 실제 이탈 고객의 절반 정도만 포착, 놓치는 비율 높음.

3. BAL (Balanced Accuracy) : (재현율 + 특이도)
Balanced Accuracy 최대 (thr=0.486)
TPR 0.816 → 이탈을 가장 많이 포착.
예측 이탈률 44.55% → 실제보다 +19.3%p 과대.
장점: 이탈을 최대한 잡고 싶을 때(리텐션 팀, 해지 방지 캠페인 등).
단점: FP 많아짐 → 정상 고객까지 타겟팅 가능성↑.
4. F1 : 정밀도(Precision)와 재현율(Recall)의 조화평균. 양쪽이 균형 잡혀야 값이 높음
5. MCC (Matthews Correlation Coefficient) : 혼동행렬 4칸(TP, FP, TN, FN)을 모두 고려한 종합 점수. +1이면 완벽, 0이면 랜덤, -1이면 완전 반대 예측.
MCC 최대 (thr=0.6165) → 균형 분류 추천
ACC 0.771, MCC 0.452 → 전체적으로 균형 잡힌 분류.
TPR 0.689 / TNR 0.798 → 양/음 모두 높은 수준.
예측 이탈률 32.50% → 실제보다 +7.3%p 과대.
장점: 잘못된 분류 비용(이탈/잔존 모두) 최소화.
단점: 재현율이 0.689로 0.5보다 낮아, 이탈 고객 일부 놓칠 수 있음.

6. TPR (Recall, 재현율)	: 실제 이탈 중 맞게 예측한 비율. 높을수록 이탈을 놓치지 않음, 하지만 FP가 늘어날 수 있음
7. TNR (Specificity, 특이도) : 실제 잔존 중 맞게 예측한 비율. 높을수록 불필요하게 이탈로 찍는 걸 줄임.
8. 예측 이탈률 : (TP+FP)/전체 → 모델이 예측한 전체 중 이탈이라고 분류한 비율
9. 실제 이탈률과의 편차 : 예측 이탈률 - 실제 이탈률. 양수면 과대추정, 음수면 과소추정.

포인트
0.5는 이탈을 넉넉히 잡아 **재현율↑(0.794)**이나, 이탈률을 43.0%로 과대추정.
**ACC 최대(0.705)**는 전체 정확도가 가장 높고, **예측 이탈률 23.4%**로 실제 25.25%와 오차 1.86%p밖에 안 돼서, “비율 측정” 관점에서 가장 근접.
**MCC 최대(0.6165)**는 혼동행렬 네 칸을 가장 잘 균형 잡아 분류 정확성이 가장 견고(정밀도·재현율 균형) — 운영상 라벨 정확도가 목표면 이 값을 권장.

2) 목적별 “최적 임계값” 제안
A. “고객이탈률을 제일 정확하게 측정” (비율 추정 정확도)
권장 임계값: thr = 0.705 (Accuracy 최대점)

예측 이탈률 23.4% vs 실제 25.25% → 편차 −1.86%p (가장 작음).

TPR 0.553, TNR 0.874 → 라벨 기준으론 보수적(이탈 적게 잡음)이지만, 총 이탈 비율 추정은 가장 근접.

참고: 이탈률 “측정(추정)” 자체는 임계값 없이 확률을 보정(calibration)한 뒤 평균 확률(=예상 이탈률)을 쓰는 게 제일 정확해. 지금은 라벨 기반 비교라 0.705가 최적이지만, 다음 섹션의 캘리브레이션을 적용하면 더 깔끔해진다.

B. “가장 정확하게 분류(양/음 모두 공정)”
권장 임계값: thr = 0.6165 (MCC 최대점)

ACC 77.1%(+5.2pp vs 0.5), MCC 0.452(최고), F1 0.603,

TPR 0.689 / TNR 0.798 → 양/음 균형이 가장 좋음.

이 값은 운영 알림/티켓팅 등 잘못된 분류 비용을 균형화할 때 적합.

C. “이탈 놓치지 않기(재현율 극대)”
권장 임계값: thr ≈ 0.486 (Youden J & Balanced Acc 최대점)

TPR 0.816로 최고. 다만 FP↑로 이탈률 과대추정(44.6%).

3) 그래프 해석 스냅샷
metrics_vs_threshold: 임계값이 커질수록 TPR↓ TNR↑가 교차, Accuracy는 ~0.70 근방에서 최대. Balanced Accuracy는 ~0.49 근방이 피크.

ROC/PR + 마커: 각 최적점이 곡선 위에 찍혀 있어서 목표 함수별 포지션 차이가 명확.

혼동행렬 비교:

0.5: TP=401 / FP=460 → 이탈을 넓게 잡아 과다 예측.

0.486: TP=412 / FP=479 → 더 넓게 잡아 가장 과다.

0.6165: TP=348 / FP=302 → 균형적.

0.705: TP=279 / FP=189 → 보수적, 이탈률 추정엔 근접.

4) 실제 운영 반영 가이드
목표에 따라 고정 임계값 선택

비율 측정(집계용): thr=0.705

분류 정확도(운영용): thr=0.6165

코드에 상수로 박아두고, 리포트에 두 기준 모두의 집계치를 병행 보고하면 의사결정 투명성↑.

캘리브레이션(강력 추천)

Platt(로지스틱) 또는 Isotonic으로 확률 보정 → 평균 확률=예상 이탈률로 직접 쓰면 임계값 문제 없이 이탈률을 가장 정확히 추정 가능.

보정 전후 **브라이어 점수(Brier score)**와 Reliability plot으로 검증.

데이터 누수 방지 & 일반화

지금 튜닝은 테스트셋에서 측정된 값이니, 실전선 훈련→검증(튜닝)→테스트 3-way 분할 또는 교차검증 기반 임계값 평균으로 고정하자.

세그먼트별 임계값(선택)

남성/45+ 등 코호트별 ROC/PR이 다르면 세그먼트별 임계값이 전체 MAE/ACC를 더 낮출 수 있음.

5) 최종 추천 (요약)
**“이탈률(퍼센트) 자체를 가장 정확히 측정”**해야 한다면:
① 확률 캘리브레이션 + 평균 확률로 추정 (가장 정확).
② 라벨 기반이 꼭 필요하면, thr = 0.705(Accuracy 최대) 사용 → 예측 이탈률 23.4%(실제 25.25%)로 편차 1.86%p로 최소.

“이탈/비이탈 분류를 가장 정확히” 하고 싶다면:
thr = 0.6165(MCC 최대)를 운영 기본값으로.
